# recipe-search-system

余っている食材の名前を入れると、その食材を使う料理の一覧を表示するWebアプリです。
料理名をクリックすると、Googleでその料理のレシピを検索できます。

- 約400種類の食材と、約5,300種類の料理を収録しています（`data/ingredient_recipes.csv`）。
- 自分でレシピ（料理名と材料）を追加できます。追加した分は、そのブラウザーに保存されます。
- HTML・CSS・JavaScriptだけで動きます。サーバー側の処理、ビルド、インストールするパッケージはありません。

## できること

### 1. 食材から料理を探す

1. 検索欄に食材名を**全角カタカナで1つ**入力します（例：`キャベツ`）。
2. 「検索」ボタンかEnterキーを押すと、その食材を使う料理名と件数が表示されます。
3. 料理名をクリックすると、「料理名 レシピ」でのGoogle検索が新しいタブで開きます。

ひらがな・漢字・半角カナなど、全角カタカナ以外の文字を入れると、検索せずに入力の案内を表示します。
完全に一致する食材名だけがヒットします（`キャベ` では `キャベツ` は出ません）。

### 2. レシピを追加する

1. 「レシピを追加する」ボタンで追加画面を開きます。
2. 料理名と、材料名（全角カタカナ、複数あれば半角カンマ `,` 区切り）を入力して「確定」を押します。
   例：料理名 `肉じゃが`、材料名 `ジャガイモ,タマネギ,ニンジン`
3. 材料に入れたどの食材で検索しても、追加した料理が出てくるようになります。

追加したデータについて：

- ブラウザーの `localStorage` に保存されるので、ページを再読み込みしても残ります。
- CSVファイルには書き込みません。別の端末や別のブラウザーとは共有されません。
- ブラウザーの閲覧データを消すと、追加した分も消えます。
- すでに登録されている「食材と料理」の組み合わせは、重複して追加されません。
- 料理名・材料名に改行は使えません。料理名には半角カンマも使えません。

## 動かし方

CSVを `fetch` で読み込むので、`index.html` をダブルクリックで直接開く（`file://`）と動きません。
ローカルでWebサーバーを立てて開いてください。

```powershell
# リポジトリのフォルダで実行（Pythonが入っている場合）
python -m http.server 8000
```

ブラウザーで http://localhost:8000/ を開きます。VS Code の Live Server 拡張などでも動きます。

GitHub Pages など、静的ファイルを配信できる場所に置けばそのまま公開できます。

## ファイル構成

```
recipe-search-system/
├── index.html                  画面（検索画面と追加画面）
├── css/style.css               見た目
├── js/
│   ├── main.js                 起動処理と画面の操作（入力チェック・結果表示・画面切り替え）
│   ├── recipeData.js           CSVを読み込み、「食材名 → 料理名の一覧」の表を作る
│   ├── recipeSearch.js         検索と、追加データの確認・反映（RecipeSearch クラス）
│   └── recipeStorage.js        追加データのブラウザーへの保存と読み込み
└── data/ingredient_recipes.csv レシピの元データ
```

### 処理の流れ

1. ページを開くと、`recipeData.js` がCSVを読み込み、食材名をキーにした `Map` を作ります。
2. `recipeStorage.js` が、ブラウザーに保存してある追加データを読み込み、その `Map` に足します。
3. 検索すると、`recipeSearch.js` が入力した食材名で `Map` を引き、料理名の一覧を返します。
4. レシピを追加すると、内容を確認してから先にブラウザーへ保存し、保存できたら `Map` にも反映します。

## データ（CSV）の形式

`data/ingredient_recipes.csv` は、1行に「食材名,料理名」の組を1つずつ書いたUTF-8のCSVです。

```csv
食材名,料理名
アイビキニク,ハンバーグ
アイビキニク,煮込みハンバーグ
キャベツ,ロールキャベツ
```

- 1行目は必ず `食材名,料理名` にします（違うと読み込みエラーになります）。
- 1つの料理に材料が複数あるときは、材料の数だけ行を書きます。
- 食材名は全角カタカナで書きます（検索欄は全角カタカナしか受け付けないため）。
- 列は2つだけです。食材名・料理名に半角カンマは入れられません。空行は読み飛ばします。
- 同じ組み合わせが複数あっても、1つとして扱います。

## 動作環境

ES Modules と `localStorage` に対応した最近のブラウザー（Chrome・Edge・Firefox・Safari）。
スマートフォンの画面幅でも使えます。JavaScriptを無効にしていると動きません。
